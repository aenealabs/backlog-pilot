# Personas

Drafts use a shared persona library, so stories are written for the same people every time.

## The library

Each persona has a name, description, goals, and pain points. Approvers add, edit, retire,
and restore personas; every change is a new version with who, when, and why.

## Proposed personas

A persona arrives as **Proposed** when the AI needed one during drafting, or when Leadership
Pilot proposes one from interviews. It joins the library only when an approver approves it.
Rejecting a proposed persona needs a reason.
